# NFSU2 Co-op — кооперативное прохождение карьеры Need for Speed: Underground 2

Мод для ПК-версии NFSU2 (2004, EA Black Box / EAGL, `speed2.exe`, x86), который делает
карьеру сетевой: несколько игроков в одной сессии, общий прогресс карьеры, синхронные
гонки с общим зачётом, зеркалирование городского трафика и AI-соперников, HUD.

Проект вырос из официального плейбука [Co-op Anything](https://github.com/cranebeaker/coop-anything)
(см. `coop-anything/games/nfs-underground-2/`) и следует его правилам: сначала «фальшивый мир»
и автотесты, потом игра; каждое «работает» подтверждено прогоном.

## Быстрый старт

### 1. Собрать

```powershell
cd "<repo>\nfsu2-coop"
.\toolchain\install.ps1        # компилятор i686, ENet, MinHook, ImGui, python-зависимости
.\build.ps1                    # coopd, coop-bot, coop-probe, тесты, NFSU2Coop.asi
.\tests\run_all.ps1            # полный прогон, печатает ALL OK
```

`toolchain\install.ps1` качает только официальные релизы и сверяет SHA-256
(см. `toolchain/catalog.yaml`). Компилятор ставится в `C:\nfsu2-toolchain`, потому что
GCC не умеет жить в пути с пробелами; в `toolchain\mingw32` создаётся junction.

### 2. Поставить в игру

```powershell
.\install.ps1 -GameDir "C:\Games\NFS U2 coop mod\game"
```

Копирует `NFSU2Coop.asi` и `nfsu2coop.ini` в `<game>\scripts\`. Загрузчик — `dinput8.dll`
(Ultimate ASI Loader из Widescreen Fix, уже стоит в этой сборке). Ничего в `.exe`,
сохранениях и оригинальных файлах игры не меняется; удаление мода — удалить два файла.

### 3. Играть

1. Хост: в `scripts\nfsu2coop.ini` поставить `Host=1`, запустить игру.
2. Гости: `Host=0`, `Server=<IP хоста>` (или IP релея), запустить игру.
3. В игре: **F6** — хост открывает событие `EventId` из конфига (лобби), гости видят
   приглашение и жмут **F5** (готовность). Отсчёт 5 с, затем гонка.
4. Гонку каждый запускает у себя сам (пока нет привязки `StartEvent`), мод синхронизирует
   старт, зачёт, финиш и начисление карьеры.
5. **F7** — сообщить хосту, что событие пройдено (аутран, спонсор, журнал, DVD — тип
   задаётся ключом `careerKey(type, EventId)`); награда начисляется всем и ровно один раз.
6. **F8** — скрыть/показать HUD, **F9** — перезапросить состояние у хоста.

Полный список горячих клавиш и параметров — `docs/INSTALL.ru.md`.

## Как это устроено (коротко)

* **Хост — единственный источник правды**: директор гонки, общий журнал карьеры,
  трафик и AI-машины. Клиент владеет только своей машиной.
* **Трафик не симулируется дважды.** Машины существуют в движке хоста; клиенты получают
  их трансформы и показывают псевдо-машины, а свой локальный трафик прячут. Поэтому
  рассинхрона «два разных трафика» не бывает по построению.
* **Карьера — журнал событий.** По сети идёт только ключ события; деньги и репутация —
  чистая функция от ключа, одинаково вычисляемая на всех машинах. Повторная доставка
  не платит дважды.
* **Зачёт по времени финиша, а не по порядку пакетов.** На плохой сети быстрый игрок
  может прислать финиш позже — места всё равно пересчитываются по времени.
* **Дайджесты и ремонт.** Каждые 2 с стороны сравнивают хэши состояния гонки и карьеры;
  при расхождении — запрос полного снапшота, а не «молчаливое» расхождение.

Подробно: `docs/ARCHITECTURE.ru.md`, `docs/PROTOCOL.ru.md`, `docs/SYNC-RULES.ru.md`.

## Что проверено, а что нет

Прогон `.\tests\run_all.ps1` (27.10.2026, Windows, i686 MinGW 16.2):

```
core tests    14 тестов / 120 проверок  ALL OK
sync tests     6 тестов /  70 проверок  ALL OK
net tests      2 теста  /  24 проверки  ALL OK   (25 % потерь + 10 % дублей; разрыв 1.2 с)
probe          10/10 якорей, pattern scan нашёл Player::ClearZone по сигнатуре
two processes  coopd + 2 бота: гонка завершена, career digest совпал, +500 $ / +20 rep
```

В игре (запуск `speed2.exe` с установленным `.asi`):

* мод загрузился, нашёл `speed2.exe`, разобрал PE, **разрешил 10/10 документированных
  якорей**, поставил хук `EndScene`, поднял ImGui;
* сама игра в этой среде падает с `0xC0000005` на смещении `0x3DBBBA` **и без мода**
  (проверено на чистом запуске) — поэтому визуальную синхронизацию машин здесь
  проверить нельзя. Это ограничение среды, а не мода; см. `docs/KNOWN-ISSUES.ru.md`.

Идентичность игры, на которой всё проверялось:

## Структура

```
nfsu2-coop/
  src/core/        сеть, протокол, мир, правила гонки, карьера, сессии  (портируемо, без Windows)
  src/game/        PE-сканер, привязки к памяти, D3D9/ImGui HUD
  src/plugin/      NFSU2Coop.asi: DllMain, поток, горячие клавиши
  src/apps/        coopd (выделенный хост), coop-bot (безголовый клиент), coop-probe (RE-отчёт)
  tests/           core/sync/net-тесты, фальшивый мир, chaos-прокси, 2-процессный прогон
  toolchain/       каталог инструментов, установщик, закреплённые SHA-256
  docs/            архитектура, протокол, правила синхронизации, привязки, сборка, тесты
  vendor/          ENet 1.3.18, MinHook 1.3.4, ImGui 1.91.9b (исходники, MIT/BSD)
```
