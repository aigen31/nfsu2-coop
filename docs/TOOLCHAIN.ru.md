# Инструментарий

Каталог: `toolchain/catalog.yaml`. Установщик: `toolchain/install.ps1`.
Он качает только официальные релизы и сверяет SHA-256; ничего не исполняется из
интернета «как есть».

## Что ставится автоматически

| Инструмент | Версия | Куда | Зачем |
|---|---|---|---|
| MinGW-w64 i686 (winlibs) | GCC 16.2.0, UCRT r3 | `C:\nfsu2-toolchain` | собрать 32-битный `.asi`, хосты и тесты |
| ENet | 1.3.18 | `vendor/enet` | UDP-транспорт с надёжным каналом |
| MinHook | 1.3.4 | `vendor/minhook` | хук `IDirect3DDevice9::EndScene` |
| ImGui | 1.91.9b | `vendor/imgui` | HUD |
| pytest / pyyaml / pefile | — | Python | Python-инструменты coop-anything, PE-разбор |

```powershell
.\toolchain\install.ps1            # доустановить недостающее
.\toolchain\install.ps1 -Force     # перекачать и переразвернуть
.\toolchain\install.ps1 -Only mingw
Get-Content toolchain\INSTALLED.json
```

`vendor/` лежит в репозитории исходниками (MIT/BSD), поэтому клон собирается без сети;
`install.ps1` нужен для компилятора и python-зависимостей.

## Что рекомендуется поставить руками

Эти инструменты не бандлятся (большие, с лицензиями или требуют аккаунта), но без них
не снять привязки к памяти. Полные ссылки и версии — в `toolchain/catalog.yaml`.

| Инструмент | Роль | Зачем именно здесь |
|---|---|---|
| **x64dbg** (уже установлен) | отладчик | `toolchain\tools\x64dbg\release\x32\x32dbg.exe`; hardware-watchpoint на запись в `[0x89CCF8]` находит функцию спавна машины, где привязывается модель |
| **Ghidra 11.x** | декомпилятор | разобрать `speed2.exe` вокруг якорей, найти цепочку указателя машины и запуск события |
| **x64dbg** (32-бит) | отладчик | breakpoint на `Player::ClearZone` (0x5FFE70), `this` → объект машины |
| **Cheat Engine 7.x** | сканер памяти | pointer scan до статической базы для машины, денег, трафика |
| **System Informer** | процессы/потоки | смотреть карту памяти и потоки игры |
| **Frida 16.x** | динамическая инструментация | быстрые эксперименты без пересборки `.asi` |
| **REA** (`npx rea-agents setup`) | RE-MCP для агента | рекомендован Co-op Anything для глубокого RE |
| **NFS-VltEd 4.x** | редактор данных NFS | списки событий, плотность трафика, треки |
| **Wireshark 4.x** | дамп пакетов | если пир не сходится — видно, что реально летит по UDP |
| **Clumsy 0.3** | хаос-сеть на Windows | потери/задержки для настоящей игры (в тестах есть свой прокси) |
| **Ultimate ASI Loader** | загрузчик модов | уже стоит как `dinput8.dll` |
| **Nucleus Co-op** | split-screen | два игрока на одном ПК, если сеть не нужна |
| **Steamworks SDK** | релей | Spacewar-релей без проброса портов (нужен партнёрский аккаунт) |
| **VS Code** | редактор | удобно править C++/ini |

## Проверка версий

```powershell
& C:\nfsu2-toolchain\bin\g++.exe --version
python -c "import yaml, pefile, pytest; print('ok')"
```

## Добавить свой инструмент

1. Добавьте запись в `toolchain/catalog.yaml`: `id`, `version`, `url`, `sha256`, `why`.
2. Если он нужен для сборки — положите его в `bundled` и обработайте в `install.ps1`
   (скачивание → проверка хэша → распаковка).
3. Если это ручная установка — в `recommended`, с официальной ссылкой.
4. Никаких `curl | sh`: только скачать файл, проверить SHA-256, распаковать.
